# 锈湖（Rusty Lake）系列谜题分层提示素材

本文件是 puzzle_hint 工具的参考素材库。puzzle_hint 工具在调用子 agent 生成提示前，会读取对应谜题的素材，注入到子 agent 的 prompt 中。子 agent 本身无工具权限，不会自行检索。

每个谜题提供三个层级的素材：
- **方向层**：该观察什么（depth=0 用）
- **机制层**：谜题运作逻辑（depth=1 用）
- **脚手架问题**：引导玩家定位卡点的追问（scaffold 模式用）

⚠️ 本文件**严禁包含具体解法/操作步骤/数值**。只写"指向"和"逻辑"，不写"怎么做"。

---

## 谜题：water-valve（水闸谜题）

**场景**：玩家在锈湖某章节遇到一个带水位刻度的水闸装置，需要调节水位通过。

- **方向层素材**：留意墙上水位刻度的排列方式，以及旁边是否有可转动的把手或齿轮。观察刻度之间是否有重复或递增规律。
- **机制层素材**：水位刻度对应闸门齿轮的转动次数，转动次数的提示藏在同一房间的其他物件上（如画作、钟表、日记）。需要把"提示来源的数字"映射到"齿轮转动次数"。
- **脚手架问题**：
  - 你在房间里都看到了哪些可交互的物件？
  - 墙上刻度有几位？是递增还是有重复？
  - 除了水闸，还有没有什么东西上面也有数字或符号？

## 谜题：chapter3-lock（第三章密码锁）

**场景**：一扇带四位密码锁的门，密码线索分散在房间各处。

- **方向层素材**：这扇门的密码不在门上，在房间里。检查所有带文字或图案的物件——画像、书本、抽屉里的纸条。
- **机制层素材**：密码的四位数字分别对应房间里四件物品上的某个标记，顺序由物品上的小图标（如季节、方向、数字）决定。不是随便凑四个数，而是"按顺序读标记"。
- **脚手架问题**：
  - 你找到了几件可能藏线索的物品？
  - 每件物品上有没有小图标（季节/方向/序号）？
  - 这些图标能不能排出一个先后顺序？

## 谜题：radio-code（收音机频率谜题）

**场景**：一台老式收音机，需要调到特定频率才能触发下一步。

- **方向层素材**：收音机的频率刻度盘是关键。房间里应该有某样东西记录了目标频率——可能是海报、唱片标签或墙上的涂鸦。
- **机制层素材**：频率以数字形式出现在另一件物品上，但不是直接标的——需要做一个简单的单位或符号换算（比如"FM 92.5"对应刻度盘上的某段）。换算关系在同房间能找到。
- **脚手架问题**：
  - 你在房间里有没有看到带数字的物品（非收音机本身）？
  - 那个数字旁边有没有符号或单位提示？
  - 收音机刻度盘的读法和那个数字能不能对上？
