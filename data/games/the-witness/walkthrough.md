# The Witness - Partial Walkthrough Notes

Coverage: route and mechanic guidance only; no individual panel answer database.

1. Start from simple panels and observe how each new panel changes the rule.
2. Follow lit cables after solving panels.
3. Treat each island region as a local lesson around a puzzle family.
4. If a panel seems impossible, look around the environment before assuming the rule is only on the grid.
5. Activating regional yellow boxes contributes to mountain progression.
