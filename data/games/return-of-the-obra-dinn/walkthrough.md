# Return of the Obra Dinn - Partial Walkthrough Notes

Coverage: deduction workflow only; no full fate table.

1. Use Memento Mortem on each corpse or trace.
2. Listen to the audio before examining the frozen scene.
3. Record concrete evidence: names spoken, job clues, uniforms, relationships, deck location, and cause of death.
4. Solve in clusters instead of forcing isolated guesses.
5. Preserve spoiler control: evidence hints first, direct identities only on explicit request.
